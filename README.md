### Instructions for running

This project can be run using maven, by using the run option in Maven -> Pacman -> Plugins -> javafx -> (run)
The project can also be run from any .java file, by using visual studio code, and running the code (the "play" icon in the top-right corner).
After selecting "play", press the launcher from the drop down, when asked.


## Optional cosmetic extras

For non-windows users, the main font used in the game "Press Play 2P", available at google fonts, can be downloaded in order to have these visible aswell. A default fallback font is used, in case the font has not been installed.
